### Deploy simplificado (YA NO necesita hacks)
```bash
# En Windows: commit y push
git add -A && git commit -m "descripción" && git push origin main

# En VPS:
cd /apps/delfos-ai
git pull origin main
docker compose build mirofish
docker stop mirofish && docker rm mirofish
docker compose up -d mirofish
sleep 15
# Regenerar lock si se agregaron deps nuevas:
docker exec mirofish bash -c "cd /app/backend && uv lock && uv sync"
```

### IMPORTANTE: .env no está en git
El archivo `.env` debe crearse manualmente en cada ambiente:
- Windows: `C:\dev\delfos-ai\delfos-ai\.env`
- VPS: `/apps/delfos-ai/.env`

```
LLM_API_KEY=...
```
